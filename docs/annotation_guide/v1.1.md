# 中文网络小说名字识别标注规则

版本 1.1  |  修订日期：2026年10月1日（v1.0 定稿于2026年9月30日；修订见文末“修订记录”）

本手册用于单人制作中文网络小说名字识别的人工标准答案，比较不训练的抽取式模型、使用弱标签训练的抽取式模型和生成式模型。采用位置级、平面标注：仅标命名表达，每处按本次指称确定一个类型。

**核心界线：** 能确定说的是谁、是什么，并不意味着这段文字就是名字。

## 使用速查

| **先问什么** | **操作** |
| --- | --- |
| 这一处是在使用名字吗 | 是名字才继续；明确的代词、类别、职业或普通描述不标；有具体歧义则待审。 |
| 名称边界在哪里 | 框原文连续的完整名称，排除外加称谓、修饰与语法成分；不做嵌套。 |
| 这一处指什么 | 在六类中选一个；不能只按相同字串或某个动词套类型。 |
| 证据是否足够 | 本章判断本次用法；可用有出处的跨章证据核实名称知识，并记录依赖。 |

## 固定范围

| **类型代码** | **纳入范围** |
| --- | --- |
| person | 人物名称，包括玩家、非玩家、异种化的人；姓名、化名、昵称及合格的人物专称。 |
| organization | 组织、机构、团体的名称。 |
| location | 地点名称，包括城市、车站、分区、建筑。 |
| dungeon | 副本或游戏关卡的名称。 |
| item | 命名的游戏物品，包括道具、药剂、车票等。 |
| trait | 有名称的特性、延伸特性及职业能力。 |

每个范围必须与原文一字不差，包括错字、前导零、内部标点和作者的不同写法。“101紧急避难”与“101号紧急避难”各按本处原文标，不在标注时改写或补字。

无名字的人物不纳入；职业、玩家等级、进化率等属性不纳入。待审、跨章依赖和不计分都是辅助状态，不是额外实体类型。正文内的例句用于说明规则；除已给定的名称信息外，构造例句不表示新增小说事实。下文【】仅表示框选范围。

## A 算不算名称

### A1 泛称和代词

**选择：** 不标。“玩家、女人、男人、他、您、富二代、大学生、小姑娘”作为身份描述或代词使用时，均不标，即使上下文能确定具体人物。

**理由与风险：** 本任务识别名字，不要求收集人物的每一种指称。同一人物用姓名出现时标、用代词出现时不标，符合任务范围。

### A2 普通物件

**选择：** 普通物件不标；明确作为游戏物品名称使用的表达标为 item。“斧头、手机、钥匙、镜子、吊灯”等，不因重要、特殊或由系统发放就自动成为名字。

“车票”作为物品大类不标；只有证据明确表明“车票”本身是固定物品名称时，才按名称标。“自愈剂、超级跑鞋、回程票”按已确认的命名物品处理，每处仍要核实当前用法。

**理由与风险：** 名称可以对应一类可重复获得的物品，不要求全书只有唯一实物。应区分“名称看起来普通”和“只是普通类别”。

### A3 描述性说法和引号

**选择：** 普通描述默认不标，明确命名用法除外。“一幅赝品、鲜红的剑、让人神魂颠倒的好东西”仅描述物件时不标；名称字段、明确命名句或其他可靠命名证据可以确立其名称用法。

明确道具语境中的引号可作为命名线索；引号不是必要条件，也不是充分条件。已确认的“超级跑鞋”在带引号、无引号或“①超级跑鞋”等列表形式下使用名称时，均框【超级跑鞋】；外部引号和序号不框。

**风险：** 仅有外观、功能、评价、反复出现或稳定指向同一物件，不能单独证明命名。反过来，不能因正式名称像一句描述就排除。

### A4 普通场所和机构

**选择：** 普通说法不标；有证据的名称和名称简称标。“房间、二楼、餐厅、古堡、山庄、实验室、政府、警方”等作为普通类别或回指用语时不标。

“古堡”即使回指“月季花古堡”，仍默认是通名回指；只有被确立为独立专称时才例外。“汀城、月季花古堡、深蓝实验室、特事局”等在本处承担命名功能时纳入。

**风险：** 能恢复出完整名称不等于当前片段本身是名称。不能把所有可回指已知对象的普通词一起纳入。

### A5 等级加类别

**选择：** 作为等级、属性或类别表达时不标，包括“E级副本、D级副本、C级道具、高级玩家、E级玩家、随机副本”。若后面跟具体名称，只框名称。

**理由与风险：** 这些表达说明对象属于哪一类，而没有给出对象的名字。名称内部本来具有的字母、数字或“级”等字必须保留；不按字符列表机械删除。

### A6 化名外号和伪装名

**选择：** 姓名、化名、玩家昵称及固定别称，在本处承担人物命名功能时标 person；边界按 B 部分处理。

| **表达及用法** | **标注** |
| --- | --- |
| 路人甲作为人物昵称 | 【路人甲】 person |
| 路人甲仅表示职业 | 不标 |
| V·范肖或范肖作为人物化名 | 【V·范肖】或【范肖】 person |
| 何先生中的何为姓氏 | 【何】先生 person |
| 假何普中的假为外加修饰 | 假【何普】 person；符合 A7 的整串固定别称才整体框 |

真实姓名、昵称和职业可以不同，也可以同形。例如，“职业是超市老板”不标职业；“昵称是神说要有光”“名字是楚云飞”分别标其中的名称。“路人甲”即使同时是职业和昵称，也逐处按功能判断。

**风险：** 标出“何普”不代表认定被指称者是真正的何普。NER 不要求确定真实身份；如需归并何普、V·范肖、范肖等别名，或记录冒充关系，另设记录，不以此改变当前名字边界。

### A7 人物专称与职业身份称呼

**选择：** 作为人物名字使用的称号、代号或固定专称，整体标为 person；仅表示职业、职位、身份或其他属性时不标。不能给同一词全书固定一个“标／不标”的结论。

- 明确命名或称呼证据可以确立专称。例如“你们可以称呼我为魔术师”；后续确实承接这一专称用法的出现位置标 person，不要求它是系统登记的玩家昵称。

- 没有明确命名句时，结合本章语境，并按补充规则核实必要的跨章证据。仅指向具体人物、作主语或反复出现，不足以认定为名字。“经理”“医生”等职业或身份回指仍不标。

- 专称不要求全书唯一，也不要求人物没有其他名字。蛾术可以同时被称为“蛾术”和“魔术师”；另一人物也可以使用“魔术师”。只要本处命名功能明确，都标 person。

- “职业是魔术师”“魔术师是一个职业”“魔术师或相关职业的玩家”等明确职业、类别用法不标。跨章得知人物的真实身份，不能把这些表达改成人物名称。

- 已确定是人物专称，只是不知道指哪位人物，照常标 person。若专称与职业、身份回指两种解释仍无法裁决，记录待审。

**边界与风险：** 完整框选已确认的专称，排除外部“这位、超级玩家”等修饰。专称内部即使含有职业或称谓字样，也不机械拆除。“公爵夫人、提箱人、纸役师、画女、魔术师”等均按这一原则判断，不凭字面认定职业或专称。

## B 名称边界

本节仅规定已纳入标注范围的名称应框多长。先按 A 部分判断是否使用名称，再处理边界。

### B1 名字带称谓

**选择：** 采用原选项①，只框名字本体，单字也框。姓名后外加的职业、职务、敬称和亲属式称呼不纳入姓名。

| **原文** | **标注范围** |
| --- | --- |
| 唐医生 | 【唐】医生 |
| 尼塞大师 | 【尼塞】大师 |
| 琅琅姐 | 【琅琅】姐 |
| 吴组长 | 【吴】组长 |
| 俞女士 | 【俞】女士 |
| 嘉鱼妹妹 | 【嘉鱼】妹妹 |
| 何先生 | 【何】先生 |

若整串已作为人物的固定专称或别名，按 A6、A7 整体标注，例如命名用法的【公爵夫人】【魔术师】。

**理由与风险：** 边界不随剩余姓名的字数变化。不能看见“医生、先生、师”等字样就自动删除；必须先区分外加称谓与名称本身。

### B2 名字套名字

**选择：** 平面标注：同一处完整名称只标一个范围，不做嵌套，不重复标其内部的短名或类别词。

| **完整标注** | **内部不另标** |
| --- | --- |
| 【月季花古堡】 | 古堡 |
| 【E27-014区】 | 014区 |
| 【玩家互助会】 | 互助会 |
| 【魔术师的馈赠】 item | 魔术师 person |

较短名称在别处独立出现时仍逐处判断。例如，独立使用的分区名【014区】可标；“古堡”作为普通场所回指仍不标。

**风险：** 完整名称不等于最长的一串文字。外加修饰语不框，相邻或并列的独立名称分别标注；不能把名称内部所有片段都加入自动匹配名单。

### B3 粘连的字和内部标点

**选择：** 按本处语义和句法判断，不设置机械删除字表。“说、道、的、玩家”等只有属于名称外的动词、助词或修饰语时才排除；属于名称内部则必须保留。

| **原文及条件** | **标注范围** |
| --- | --- |
| 人物名为沈新，道表示说话 | 【沈新】道：“……” |
| 假设人物名为沈新道，后面接说 | 【沈新道】说：“……” |
| 路人甲在本处为人物昵称 | 玩家【路人甲】 |
| 玩家互助会是完整组织名称 | 【玩家互助会】 |
| 路人甲在本处为人物名称 | 【路人甲】的道具 |
| 不会疲劳的双腿是完整特性名称 | 【不会疲劳的双腿】 |

“小、老、假”等按其实际作用处理。“假何普”默认标为假【何普】，整串被确立为固定别称时才整体标；“小X”“老X”也不能一律删除前缀，或仅因反复指向某人就认定整串是固定名。

名称外的引号、书名号、括号、列表序号和句末标点不框；名称内部的字符照原文保留，例如【V·范肖】的间隔号、【E27-014区】的连字符与前导零。

**风险：** 孤立的“沈新道：‘……’”可能无法区分“沈新＋道”与“沈新道”。应核对上下文，必要时按补充规则查证；仍不清楚则待审，不能自动删去“道”。

## C 标什么类型

每处只给一个类型。相同字串可以在不同位置指不同对象；类型依据本次指称，不把字串当成全书固定的类型键。

### C1 同一个名字指不同东西

**选择：** 按本处实际指称分类。“砍头魔”指关卡时标 dungeon；指具体角色且符合 person 范围时标 person。“好味道鲜肉供应厂”指任务关卡时标 dungeon，明确指物理厂区或建筑时标 location。

| **假设例句** | **类型** |
| --- | --- |
| 本次副本名为【砍头魔】。 | dungeon |
| 异种化的人物【砍头魔】举起刀追了过来。 | person |
| 通关【好味道鲜肉供应厂】后即可领取奖励。 | dungeon |
| 【好味道鲜肉供应厂】这座建筑的屋顶塌了。 | location |

**拿不准时：** 先读本章相关上下文。若已确认是副本名称，而本处只说“进入、离开”，没有明确区分关卡与场所，默认 dungeon。其他无法裁决的类型冲突进入待审，不设置适用于所有冲突的全局优先级。

**风险：** “进入”不能单独证明是地点；“怪物”也不能单独证明符合 person。范围外的对象不为了凑进六类而强行定类。

### C2 道具还是特性

**选择：** 优先依据本章对同一命名对象的明确分类，如“道具、特性、延伸特性、职业能力”。本章不足时，允许用有出处的跨章说明核实，并记录跨章依赖；不能只按名字语感判断。

“伤人不伤己、快乐隐身、有氧供给、不会疲劳的双腿”等名字，不能仅凭字面推断类别。某名已确认为道具，后文即使使用“发动”仍可为 item；“使用、发动、获得、失去”等词均不能单独定类。

**拿不准时：** 找不到可靠分类证据，或同名对象仍无法区分时待审，不默认全部归 item。

**风险：** 道具效果不自动构成 trait；职业也不等于职业能力。例如【超级跑鞋】“使奔跑时不感到疲劳”只描述效果时，不额外标一个 trait。只有另有命名证据和类别证据时，才标相应能力名称。

### C3 组织还是地点

**选择：** 先按 A4 判断是否为名称，再按本处指称区分。招聘、批准、运营等机构行为支持 organization；明确指建筑本身的楼层、墙体、坍塌等物理性质支持 location。

| **假设例句** | **类型** |
| --- | --- |
| 【第十七医院】决定招聘三名医生。 | organization |
| 【第十七医院】这栋楼的外墙出现裂缝。 | location |
| 【深蓝实验室】宣布停止与其他机构合作。 | organization |
| 【明珠酒店】这座建筑共有十二层。 | location |

**保底约定：** 对已确立的机构名称，单独出现“到、在、进入”等表达时默认 organization；已确立为建筑名称的沿用 location。不能因为机构拥有建筑或位于某地就自动切换。

同一处机构名称兼有机构和建筑含义、无法明确分开时，默认 organization，并记入判例。例如“第十七医院虽然被炸塌了，但仍在给员工发工资”的混合用法按此处理。

**风险：** 这里的默认只处理规定的情形，不能覆盖其他类型冲突。以往判例指导相同语境的处理，不强迫同字串永远保持同类。

## D 标注方式

### D1 位置级标注

**选择：** 每一处符合规则的出现都标，保存章节、起点、终点和类型。章级名称清单可以从位置级标注导出，不能替代位置级标准答案。

假设原文是“【徐获】拿出【超级跑鞋】，随后【徐获】又把【超级跑鞋】收了起来”，共有四处标注：两处 person、两处 item。

**理由与风险：** 位置级标注能区分同字串的不同用法和类型。高频主角可能主导总体成绩，因此总体之外还要报告各类型成绩和出现次数。

### D2 批量提示和逐处确认

**选择：** 允许工具提示本章其他相同字串，必须逐处确认名称资格、边界和类型。工具显示上下文，不自动把首处标签套给全章。

- 先人工确认一处，再查看同字候选；每处重新判断是否标、框多长、标哪类。

- 同字搜索结束后通读整章，检查未被高亮的新名称、错字、名称变体和别名。

- 留意“明明”的人名／副词两用、职业“魔术师”、道具“魔术师的馈赠”内部片段，以及副本名与地点名的类型切换。

**风险：** 候选列表不是全文标注范围。只检查工具已找到的内容，会系统性遗漏未知名称；不能只依据某一待评模型的候选制作标准答案而不全文查漏。

### D3 章数与抽样

**方案：** 先安排试标，再确定正式测试规模。下表是工作量预算，不是保证检出 0.05 F1 差距的统计门槛。

| **阶段** | **暂定章数** | **用途** |
| --- | --- | --- |
| 试标与开发 | 10–15章 | 发现规则漏洞，记录标注耗时、类别数量、名称多样性与系统差异。 |
| 正式测试 | 另选60–100章 | 冻结规则和系统配置后统一比较；最终数量在正式评测前确定。 |

按每章约2000字估算，60–100章约为12万–20万字。试标后根据实际出现位置数、类别分布和系统表现波动调整预算。章数较少仍可开展比较，但不能仅凭章数宣称统计把握度足够。

正式测试从预先确定的范围中，跨时期和副本分层随机抽取，避免只选一段连续剧情或名字特别多的章节。刻意补选的稀有类型、难例应另列补充测试集，不混成代表性主结果。

**风险：** 每章十个不同名字不是十份独立证据，同名重复出现也不等于独立样本。统计方法见附录一；正式测试的样本量与停止规则应提前确定，不追加到差异显著为止。[5][6]

## 补充规则和漏掉的情况

### E1 跨章查证和证据记录

本章语境用于判断当前表达的功能；允许有限、有出处的跨章查证，帮助确认名称是否成立、完整边界、同一对象的类别或专称用法。不得仅凭记忆补充未查证的小说事实。

跨章证据必须能够支持当前候选对象的判断。同字串出现在其他章节，不自动证明同一对象、同一类别或本处同为名称；当前明确的职业、类别用法仍按当前语境处理。

- 仅查清 NER 所需的问题。若专称、边界、类型已确定，不为追查真实身份而暂停标注。

- 记录“是否依赖跨章证据”及证据章节、位置或短引文。一条证据可被多处引用，不必重复抄写。

- 只有跨章证据实际影响名称资格、边界或类型的裁决时，才标记依赖。为了解人物身份而额外查阅、但不影响标签的，不计为跨章依赖。

- 查证仍不能裁决时，保留待审。当前明示与既有记录冲突时，先核对对象是否同一及是否重名，不能按旧字典覆盖本处用法。

跨章依赖标记在相关标注及对应句段上，便于报告分组结果。人工查证材料不自动成为模型测试输入，也不直接回流进本轮训练材料；系统使用的词典和检索资源须预先声明。

### E2 三种处理状态和最终待审

| **判断结果** | **处理** |
| --- | --- |
| 确认是名称，边界和类型都确定 | 正式标注。真实身份未确定，不妨碍标注。 |
| 确认是普通类别、职业、描述或代词 | 不标；普通不标内容不必逐词填写记录。 |
| 是否为名称、边界或类型存在具体且未解决的歧义 | 待审，保存位置、候选解释和疑点。 |

没有明确命名句不自动等于不是名字，也不自动等于待审。一般的普通物件、职业陈述按 A 部分处理；存在具体、合理的多种解释而无法选择时才待审。

**待审应注明具体卡在哪一步：名称资格、名称边界或实体类型。** 确认对象属于游戏道具，只解决对象类别问题，不自动解决当前表达是不是名称的问题。

完成一批章节后集中复核。能够用上下文、可靠查证或已定规则解决的，正式裁决并回查同类旧标注；仍无法可靠裁决的，保留记录，将相应句段对所有系统统一设为不计分。

不计分只改变评分范围，不删改模型输入的原文。报告排除句段的数量、原因及覆盖比例；不能因某模型做错而排除，也不能把待审静默当成非实体。具体评分处理见附录一。

### E3 名称与物品实例

名称不要求对应唯一实物。“自愈剂”在指某一瓶、几瓶或讨论该命名物品的一般性质时，都可以作为 item 名称标注；数量和量词不框。对命名物品类别的概述也可为名称用法，普通上位类“药剂、车票、道具”等仍按 A2 判断。

### E4 简称别名和身份归并

有命名证据的简称可以标，普通通名回指不标。不同表面写法照原文保留，不在 NER 标注中强制统一真名、化名、错字或冒充者。实体链接、别名归并、道具归属与人物关系均是可选的后续工作，不是完成本次标注的前提。

**名称省略后的片段，不自动成为名称简称。** 仅保留物件、场所或组织类别词时，默认作为通名回指，不标，例如“琴弦”“古堡”“互助会”。保留名称中的识别代号或其他命名成分，且上下文明确承接该名称时，可以标为简称，例如“P1药剂”中的“P1”。有明确命名证据的普通词不受这一默认排除限制。

### E5 正文范围与位置保存

主标注范围为小说正文，包括人物对话、正文内系统消息、道具说明、列表等。章节标题、作者的话、广告、网站导航和读者评论不纳入主测试；导入时需明确标出这些边界。

在标注前冻结每章文本版本。所有清洗、换行处理和编码转换均在冻结前完成；冻结后不随意删空格、换标点或改字。必要变更须更新文本版本并重新核对位置。

位置按从0开始、右端不包含的字符区间保存，即 [start, end)。计数单位固定为 Unicode 码点；原文[start:end]应严格等于标注文字。标注工具内部若使用其他计数方式，导出时统一转换。

正式记录至少包含章节标识、起点、终点和六类之一的类型；可以附存原文片段用于校验。另行记录文本版本、规则版本、待审状态、跨章证据和不计分句段，不把这些信息扩充为实体类型。

### E6 单人标注的一致性检查

建议间隔一至两周，随机抽取约10%–20%的章节，隐藏旧标注后重新标一次，比较漏标、边界和类型差异。此比例是暂定质检预算。报告中称为“标注者自身一致性”，不称为多人一致性。

每次形成新判例，记录原文位置、裁决和理由。若修改规则，提升版本并回查所有受影响的旧标注；最终成绩注明文本、规则及金标准版本。不要只修刚遇到的一处。

## 总原则

先判断本处是否使用名称，再确定边界，最后确定类型。每一步都应能说明依据；同样的语境采用同样的处理，相同字串不必得到同样标签。

证据处理顺序为：先读本章明示与相关语境；必要时核实有出处的跨章名称知识；依据适用的规则和判例裁决；无明确区分时只使用已经写明的默认约定。跨章信息不能推翻当前明确的职业、类别或描述用法。

确认是名称则标；确认是普通表达则不标；名称资格、边界或类型存在真实未决歧义则待审。身份不明与名称用法不明必须分开。待审不是第七类，也不是默认不标。

一章完成前，核对三件事：所有出现位置是否逐处处理；批量提示之外是否全文查漏；疑难和跨章依据是否留下记录。进入正式评分前，统一完成裁决或不计分处理。

## 附录一 实验和评分实施说明

本附录规定如何把标注用于系统比较。正文 A 至 E 决定怎样标；以下内容负责数据划分、模型输出和成绩解释。工作量预算不等于统计保证。

### 训练词典与测试的边界

先确定试标／开发与正式测试划分，再构建本轮弱标签训练材料。正式测试章不进入本轮训练；不得用测试人工答案补词典、调整提示词、选择阈值或挑选模型。开发章可以用于这些调整，但不再作为独立正式测试章。

训练章和测试章出现相同名字本身不构成泄漏。若允许使用全书词典或包含测试原文的外部资源，应单独声明这种资源条件；纯本章输入、带词典或带跨章检索的系统不得在报告中混称为相同输入条件。测试人工查证记录不直接回流到训练材料。

记录各系统的模型版本、训练／开发数据、提示词、阈值、词典来源和构建范围、输入窗口、分块与重叠处理、允许的检索资源。模型受长度限制而采用的切块方案也属于系统流程。所有系统使用同一版测试原文和同一评分范围。

有训练或随机生成的系统还应记录随机种子或采样设置。测试集重采样只反映数据抽样波动，不替代对训练、生成随机性的检查。

### 生成式模型的逐处输出和定位

主方案要求每一处实体单独输出名称原文、类型和包含该处名称的原文定位片段。程序依据片段还原字符起止位置；不强求模型手工计算字符编号。

| **字段** | **假设示例** |
| --- | --- |
| 原文 | 你可以叫我魔术师，我的职业也是魔术师。 |
| 名称原文 | 魔术师 |
| 类型 | person |
| 定位片段 | 你可以叫我魔术师 |

该示例只定位第一处人物专称，不扩展到第二处职业用法。定位片段须与原文连续字串严格一致；若片段或名称仍出现多次，按事先确定的规则扩大锚点、提供出现序号或判定定位失败。重试规则也须在正式测试前固定。

禁止人工参照标准答案挑选候选位置。不能定位、越界、缺少类型或返回非法类型的输出应记录为系统错误，不能悄悄丢弃后只评价成功部分。实体名称文本、位置和类型最终必须采用与抽取式模型相同的评分约定。

允许另测“名字清单＋全章匹配”版本。其固定匹配程序输出的每处位置都参与评分；匹配到职业用法、长名称内部或错误类型，正常计错。报告评价的是完整流程，并与逐处输出方案区分。

### 严格匹配与结果报告

主指标采用实体级严格匹配：章节、起点、终点和类型全部一致才算正确。边界多字、少字或类型错误均不算完整命中；部分重叠只作辅助诊断。这与 CoNLL 的严格匹配评价思路一致。[7]

| **记号** | **含义** |
| --- | --- |
| TP | 与标准答案完全一致的预测实体。 |
| FP | 没有完整匹配标准答案的预测实体。 |
| FN | 没有被完整识别出的标准答案实体。 |
| P 和 R | 精确率 P 看预测中有多少正确；召回率 R 看标准答案中有多少被找到。 |
| F1 | 精确率与召回率的调和平均。 |

总体采用 micro P、R、F1：先汇总所有可评分位置的 TP、FP、FN，再计算指标。另报六类各自的 P、R、F1 和出现次数；样本为零的类别标为无可评样本，不硬填成绩。

主结果保留全部可靠裁决的标注，包括依赖跨章证据的标注。提前标记跨章依赖句段，另报其数量、覆盖比例和分组成绩，同时报告其余可评分句段的成绩。不能把分组差异直接解释为单一模型机制的因果效果。

未决歧义以预先记录的句段范围统一设为不计分。评分时，任何与该范围有字符重叠的金标或预测均不计入 TP、FP、FN，并另报受影响的范围与数量；模型输入保留原文。分组评分使用同一套预先固定的区间归属规则。

同一系统重复输出完全相同的章节、起止位置和类型时去重；同一位置输出冲突类型则保留并按普通预测计分。无位置且最终未能定位的候选计作无效预测，计入整体 FP，并单列数量；其漏掉的金标照常计 FN。

### 样本量与差值置信区间

0.05 F1 指例如0.80与0.75之间的差值，不能单凭这个目标推出章数。检测能力还受跨章节波动、系统错误重合、统计方法和显著性标准影响。可用开发数据做先验估计，再在正式评测前固定测试量；不要用已观察到的正式测试差值反向宣称功效足够。[5]

建议采用按章成组的配对 bootstrap；连续剧情具有较强相关性时，按预先划定的剧情块成组。分层抽样时，重采样应尊重原先的分层设计。这是结合小说数据结构对配对重采样的应用，不能认为所有章节或剧情块必然独立。[6]

- 每轮从测试章或剧情块中有放回抽样；比较的系统使用同一轮抽到的内容。

- 分别汇总该轮每个系统的 TP、FP、FN，重算整体 F1，再计算两个系统的 F1 差值。

- 重复多轮，用差值分布估计95%置信区间；不先平均每章 F1 代替整体 F1。记录重采样单位、轮数和随机种子。

差值区间跨过0时，对优劣方向的证据仍不明确，不能据此宣称两者等效。正式测试量与停止规则必须预先确定。若只有少数独立剧情块，区间估计也可能不稳定，应如实说明。

少数类别若主要由几个重复名称构成，即使总出现次数很多，也不能代表丰富的名称覆盖。额外挑选的稀有类型、歧义例句或难例应作为补充测试集单独报告。

## 附录二 与常见中文NER资源的关系

以下用于说明规则来源与差异，不替代本项目的操作规则。MSR 一栏依据《MSR中文文本标注规范5.0》的公开全文，不能直接等同于所有 MSRA 数据发布版本。OntoNotes 的部分昵称和称谓细节来自其英文 NER 复核研究，不能直接当作中文官方细则。

| **问题** | **MSR规范5.0 [1]** | **OntoNotes [2][3]** | **CLUENER [4]** |
| --- | --- | --- | --- |
| A1 泛称代词 | 一般人物泛称不属于人名。 | 名字与共指分层；代词能参与共指不等于人物名。 | name面向人名及人物别称，不是所有人物指称。 |
| A7 专称昵称 | 接纳虚构人物与部分作为人名的特定名号。 | 英文复核研究讨论独特昵称，也指出边界歧义。 | 明确接纳小说人物绰号及人物别称。 |
| B1 名字称谓 | 张经理只标张；另有不可分例外。 | 英文复核研究移除普通职衔、敬称和亲属称谓。 | 姓名和职位分设类别；公开说明未穷举单姓敬称规则。 |
| C1 同字异类 | 有任务特定约定；画名中的人名仍可标为人名。 | 存在借代和类型歧义，不能简化为固定字串表。 | 要求按场景区分同名书籍、电影、游戏。 |
| C3 机构建筑 | 医院酒店列入机构，公共设施另有地点规则。 | 区分ORG、FACILITY、GPE和LOCATION。 | 公司、政府、组织、地址、景点分列，未提供完整机构建筑转换规则。 |

本项目的关键自定义内容是 dungeon、item、trait，以及小说人物专称的证据门槛。B1 的单姓边界有明确先例；C1、C3 则需按本手册独立执行，不能宣称整套规则完全沿用 MSRA、OntoNotes 或 CLUENER。

本项目不要求专称全书唯一，也不要求知道真实身份。职业属于排除项；CLUENER另设 position，因此不能把它的全部实体范围直接移入本项目。
